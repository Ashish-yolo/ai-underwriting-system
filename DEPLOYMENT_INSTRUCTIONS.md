## Backend Deployment (Render)

### Step 1: Trigger Render Deployment

Your backend is configured to deploy automatically on push to `main` branch. Render should have already detected the push and started deploying.

**Check Deployment Status:**
1. Go to https://dashboard.render.com
2. Find your `underwriting-backend` service
3. Check the "Events" tab for deployment progress

### Step 2: Run Database Migrations

After the backend deploys, you need to run the new migrations:

```bash
# Option 1: Using Render Shell (Recommended)
# Go to Render Dashboard → Your Service → Shell
cd backend
npx ts-node src/database/run-migrations.ts

# Option 2: Using Render API
curl -X POST https://api.render.com/v1/services/{SERVICE_ID}/shell \
  -H "Authorization: Bearer YOUR_RENDER_API_KEY" \
  -d '{"command": "cd backend && npx ts-node src/database/run-migrations.ts"}'
```

**Migrations to Run:**
- `008_create_connector_variables_tables_v2.sql` - Connector variables
- `009_add_execution_type.sql` - Execution type tracking
- `010_encrypt_connector_credentials.sql` - Encrypted credentials

### Step 3: Set Environment Variables

Ensure these environment variables are set in Render:

**Required:**
```bash
NODE_ENV=production
PORT=3000
DATABASE_URL=(auto-generated by Render)
ENCRYPTION_KEY=(generate using: npx ts-node src/scripts/generate-encryption-key.ts)
JWT_SECRET=(generate: openssl rand -base64 32)
SESSION_SECRET=(generate: openssl rand -base64 32)
WEBHOOK_SECRET=(generate: openssl rand -base64 32)
```

**Optional:**
```bash
REDIS_URL=redis://...  (if using Redis)
MONGODB_URL=mongodb://...  (if using MongoDB)
LOG_LEVEL=info
MAX_REQUEST_SIZE=10mb
```

**To Generate ENCRYPTION_KEY:**
```bash
# Run locally
cd backend
npx ts-node src/scripts/generate-encryption-key.ts
# Copy the output and add to Render environment variables
```

### Step 4: Verify Backend Deployment

```bash
# Check health endpoint
curl https://underwriting-backend.onrender.com/health

# Expected response:
{
  "status": "healthy",
  "timestamp": "2024-11-10T...",
  "environment": "production"
}

# Check API endpoints
curl https://underwriting-backend.onrender.com/api/policies/builder/variables

# Should return JSON array of connector variables (or empty array if no data yet)
```

## Frontend Deployment (Netlify)

### Step 1: Configure Netlify

The `netlify.toml` file has been created and will be detected automatically.

**Manual Configuration (if needed):**

1. Go to https://app.netlify.com
2. Click "Add new site" → "Import an existing project"
3. Connect to your GitHub repository
4. Configure build settings:
   - **Build command:** `npm install && npm run build:frontend`
   - **Publish directory:** `frontend/dist`
   - **Base directory:** (leave empty or set to root)

### Step 2: Set Environment Variables in Netlify

Go to Site settings → Environment variables and add:

```bash
VITE_API_URL=https://underwriting-backend.onrender.com
VITE_APP_NAME=AI Underwriting System
```

**Important:** Make sure to replace `underwriting-backend.onrender.com` with your actual Render backend URL.

### Step 3: Trigger Netlify Deployment

Since you've just pushed to GitHub, Netlify should automatically start deploying.

**Check Deployment Status:**
1. Go to https://app.netlify.com
2. Find your site
3. Check "Deploys" tab for build progress

**If Auto-Deploy Didn't Trigger:**
- Click "Trigger deploy" → "Deploy site" in Netlify dashboard

### Step 4: Verify Frontend Deployment

```bash
# Your site will be available at:
https://your-site-name.netlify.app

# Or your custom domain if configured
```

**Test Checklist:**
- [ ] Homepage loads
- [ ] Can navigate to Policy Builder
- [ ] Can log in
- [ ] Variable selector loads (check browser console for API calls)
- [ ] No console errors

## Post-Deployment Steps

### 1. Update Frontend API URL

If your backend URL changed, update it in Netlify:
1. Go to Site settings → Environment variables
2. Update `VITE_API_URL` to your Render backend URL
3. Trigger a new deploy

### 2. Test End-to-End Flow

```bash
# 1. Create sample data (using backend URL)
curl -X POST https://underwriting-backend.onrender.com/api/connectors/{CONNECTOR_ID}/sample \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "requestPayload": {"pan": "ABCDE1234F"},
    "responsePayload": {
      "score": 750,
      "totalAccounts": 5,
      "delinquentAccounts": 0
    }
  }'

# 2. Verify variables are discovered
curl https://underwriting-backend.onrender.com/api/policies/builder/variables \
  -H "Authorization: Bearer YOUR_TOKEN"

# 3. Test in frontend
# Go to https://your-site-name.netlify.app
# Navigate to Policy Builder
# Create Strategy node
# Click variable field → should see dropdown with variables
```

### 3. Run Encryption Setup

If you haven't set up encryption yet:

```bash
# In Render Shell
cd backend
npx ts-node src/scripts/generate-encryption-key.ts
# Copy the key and add to environment variables

# Test encryption
npx ts-node src/scripts/test-encryption.ts

# Encrypt any existing credentials
npx ts-node src/scripts/encrypt-existing-credentials.ts
```

## Troubleshooting

### Backend Issues

**Issue: Build fails with "Module not found"**
```bash
# Solution: Check package.json in backend folder has all dependencies
cd backend
npm install
```

**Issue: Database connection fails**
```bash
# Solution: Check DATABASE_URL in Render environment variables
# Make sure PostgreSQL service is running
```

**Issue: ENCRYPTION_KEY error**
```bash
# Solution: Generate and set encryption key
npx ts-node src/scripts/generate-encryption-key.ts
# Add output to Render environment variables
```

### Frontend Issues

**Issue: Build fails on Netlify**
```bash
# Solution: Check build command is correct
# Should be: npm install && npm run build:frontend
# Check frontend/package.json has build script
```

**Issue: API calls fail (404 or CORS errors)**
```bash
# Solution: Check VITE_API_URL in Netlify environment variables
# Should be: https://your-backend.onrender.com (no trailing slash)
# Redeploy after updating
```

**Issue: Variables not showing in dropdown**
```bash
# Solution:
# 1. Check backend is running: curl BACKEND_URL/health
# 2. Check API endpoint: curl BACKEND_URL/api/policies/builder/variables
# 3. Upload sample data if empty
# 4. Check browser console for errors
```

## Rollback Procedure

If something goes wrong:

```bash

3. Click "..." → "Publish deploy"
```
